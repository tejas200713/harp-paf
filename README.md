# HARP-PAF

HARP-PAF is organized for the frontend and backend teams to work side by side. The frontend application lives in `frontend/`.

## Frontend app

The current frontend is a research dashboard prototype with simulated jobs and illustrative data. It does not compile or execute submitted source code or provide live hardware measurements.

To run it locally:

```sh
cd frontend
npm install
npm run dev
```

The backend team can add its service in a sibling `backend/` directory when development begins.
